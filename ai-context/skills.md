- Laptop
- Desktop
- Ultra-wide

---

### Component Architecture

Every UI block should be an independent reusable component.

Example

src/components

- Navbar
- Hero
- Features
- About
- Marketplace
- Reels
- Testimonials
- FAQ
- Contact
- Footer

Each component must contain

- own styles
- own assets
- reusable props
- no duplicated code

---

### Performance Skills

Always

- Lazy load images
- Compress assets
- Optimize SVG
- Use memoization when required
- Avoid unnecessary re-renders
- Minimize bundle size
- Maintain Lighthouse-friendly structure

---

### Accessibility

Follow WCAG basics

- Semantic HTML
- Keyboard Navigation
- Focus States
- Alt Text
- Proper Labels
- ARIA only when needed

---

### Animation

Use Framer Motion carefully.

Allowed

- Fade
- Slide
- Scale
- Scroll Reveal
- Hover Effects

Avoid

- Heavy animations
- Distracting effects
- Continuous motion
